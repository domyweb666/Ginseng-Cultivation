# 像素風立繪：GIF 測試指令

先拿煉氣男一張試。試出來的 GIF 丟回給我，我看格子有沒有對齊、背景有沒有跟著動，可以的話再轉成 app 吃的格式。

## 要附的圖

`給多米/煉氣男_放大6倍_1008x1260.png`

這張是 app 裡那張 168×210 的像素圖放大六倍，一格剛好 6×6 個點。附原始那張 168×210 的話太小，生圖工具通常會自己放大然後糊掉。

## 指令

```
把附上的圖做成一張循環播放的 GIF 動畫。這是一張像素圖，每一個像素格是 6×6 個點，請保持這個格子。

不能動的：
- 背景完全不動。招牌、山、屋子、燈籠的外形、石階、石頭、草，每一格的位置和顏色都要跟原圖一樣
- 角色的臉、身體、衣服、腰繩、腳不變形、不扭曲、不起伏。不要讓整個角色上下跳，也不要做呼吸起伏
- 鏡頭不動，不要縮放、平移、震動

會動的只有這五樣，動作要慢、幅度要小：
1. 眨眼：整段動畫眨一次，閉眼只佔兩格
2. 頭頂的兩片葉子和紅果：像被微風吹，整片繞著葉柄左右擺，擺過去再慢慢擺回來。葉子本身不要做波浪狀的扭動
3. 右手提的水桶：整個水桶連同提把像鐘擺一樣小幅度前後晃，水桶本身不變形
4. 水桶裡的水面：有一兩格反光在閃
5. 屋簷下的燈籠：光微微一亮一暗，燈籠的外形不變

格式：
- 尺寸跟原圖一樣，1008×1260
- 共 24 格，每格停 0.15 秒，一輪 3.6 秒
- 最後一格要能接回第一格，循環時看不出接縫
- 只用原圖已經有的顏色。不要漸層、不要模糊、不要柔邊、不要抗鋸齒
- 每一格都要對齊 6×6 的格子，不要出現半格
- 不要加文字、外框、浮水印

請輸出兩個檔：一個 GIF，一張把 24 格由左到右、由上到下排成 6 欄 4 列的 PNG。
```

## 它如果做不到

- 如果它說一次做不了這麼大的 GIF，改成「尺寸 504×630，一格 3×3 個點」，其他不變。
- 如果它只肯給 GIF 不給那張排好的 PNG，沒關係，GIF 我可以自己拆。
- 如果它問要用程式處理還是重新生圖，兩種都可以各試一次，檔名分開存，我比較哪一種好。

## 想多試一輪的話

同一個資料夾還有分好層的兩張：`煉氣男_只有角色_透明底_1008x1260.png` 和 `煉氣男_只有背景_1008x1260.png`。三張一起附上去，指令最前面加一句：

```
第一張是完整圖，第二張是去背的角色，第三張是只有背景。請把背景當底層完全不動，角色疊在上面，只動我指定的部位。
```

## 回來之後我會看什麼

- 背景有沒有任何一格在閃或漂移
- 衣服的補丁、腰繩有沒有被擠壓
- 格子有沒有對齊，顏色有沒有多出原圖沒有的
- 首尾接不接得起來

app 現在播的是 96 格的格子圖。24 格的 GIF 可以的話，我這邊轉成 app 的格式，或是請它直接出 96 格。
