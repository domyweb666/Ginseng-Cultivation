# 像素風立繪：GIF 測試指令

先拿煉氣男一張試。附的圖只要一張：`給多米/煉氣男_放大6倍_1008x1260.png`。

## 煉氣期的待機動畫要演什麼

煉氣期在 app 裡是剛入門的雜役，立繪是提著水桶去挑水。「煉氣」本來的意思是吐納、把靈氣吸進身體。兩件事放在一起，就是一個挑水的雜役趁沒人看偷偷練功，結果功力不夠，把水灑了。

三個方向，我選第一個：

1. **偷練吐納**（推薦）：深吸一口氣，靈氣往身上聚，憋住，大口吐掉。吐得太用力，水桶晃一大下、水濺出來，嚇一跳趕快扶穩。有修仙的味道，也有雜役的笨拙，動作有大有小。
2. **挑水挑累了**：把水桶放到地上，擦汗、甩甩手，再提起來。最像雜役的日常，但看不出在修煉。
3. **拿水桶練力氣**：把水桶當啞鈴舉兩下，第二下舉不太動，手在抖。跟健身最有關，但跟「煉氣」兩個字沒關係。

之後七個境界各有一段，可以照同一個想法排：每一境演它那個境界在練的東西，煉氣吐納、築基練劍、金丹凝丹，往上越來越從容。

## 指令

```
把這張像素圖做成循環播放的 GIF 待機動畫。畫風和像素格子保持原樣，背景不動。

角色是修仙宗門裡剛入門的煉氣期雜役，提著水桶去挑水，趁沒人看偷偷練吐納。動作要大，看得出來在演：

1. 深吸一口氣，胸口挺起來、頭微微後仰，頭頂的葉子跟著豎起來，四周有幾縷淡淡的靈氣往他身上聚
2. 憋住一下，臉頰鼓起來
3. 大口吐氣，整個人放鬆，葉子垂下來，靈氣散開
4. 吐得太用力，手上的水桶晃了一大下，水濺出來。他嚇一跳趕快扶穩，然後笑一下，回到原本的姿勢

一輪大約 4 到 5 秒，節奏慢一點。
```

## 第一版的結果（2026-11-17）

格式都對（24 格、每格 0.15 秒、格子對齊、背景沒動），但動作太小，葉子和水桶只移了一兩格。那一版的指令寫了「幅度要小」，又把能動的部位一條一條限制住，它就照做了。所以這一版只講要演什麼，怎麼畫讓它自己決定。
