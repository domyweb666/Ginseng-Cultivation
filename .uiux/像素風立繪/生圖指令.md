- 生圖工具要能附圖改圖。同一個境界的四張在同一串對話裡做完，換境界再開新的一串，角色才不會跑掉。

## 指令一：完整圖

附兩張圖，第一張是那個境界的水彩原圖，第二張是畫風參考。

```
把第一張圖（水彩）重畫成像素風插圖，畫風照第二張圖。

要保留的：
- 構圖、角色的姿勢和表情、衣服的顏色與花紋、手上拿的東西、背景裡的每一樣東西，都跟第一張一樣
- 角色是小人蔘：米黃色的身體，頭頂有環紋，長兩片綠葉和一串紅果，臉旁有鬚根，腳是分岔的參根
- 圖的四周留白，邊緣像第二張那樣自然散開，不要畫框

像素風的要求：
- 整張圖用同一個大小的方格畫，每一格只有一個顏色，格子要對齊，不要出現半格
- 解析度大約寬 150 格、高 164 格，再等比例放大輸出
- 外框線用深褐色，一格寬
- 每種材質用 3 到 4 階顏色做明暗。不要漸層、不要模糊、不要柔邊、不要抗鋸齒
- 圖裡的字照第一張寫，筆畫要清楚

輸出尺寸和長寬比跟第二張一樣。
```

煉氣女生這張你已經有了，可以直接從指令二開始，把那張圖附上去當「剛剛那張」。

## 指令二：只有角色

接在同一串對話後面。大括號那一格照最下面的表填。

```
用剛剛那張像素風的圖，只留下角色，其他全部拿掉。

- 角色的大小、位置、姿勢、每一格的顏色都不要變，圖的尺寸也不要變
- 角色手上拿的、身上穿戴的東西都留著：{角色層的東西}
- 背景要透明，輸出透明背景的 PNG。做不到透明的話，背景整片填純色 #FF00FF
- 不要地面、不要影子、不要光暈
- 角色的邊緣保持一格一格的硬邊，不要羽化
```

## 指令三：只有背景

```
用剛剛那張像素風的完整圖，把角色整個拿掉，被角色擋住的地方照周圍的景補起來。

- 背景裡原本有的東西位置都不要動，圖的尺寸不要變：{背景層的東西}
- 角色手上拿的、身上穿戴的東西一起拿掉
- 地上不要留角色的影子
- 畫風、格子大小、顏色跟完整圖一樣
```

## 指令四：閉眼

```
用剛剛「只有角色」那張，只改眼睛：兩隻眼睛閉起來，各畫成一條往下彎的短弧線。
其他每一格都不要動，圖的尺寸和背景也不要變。
```

## 檔名和放哪裡

放在這個資料夾的 `出圖/` 底下，檔名用原圖的代號加用途：

- `gr0_full.png` 完整圖
- `gr0_char.png` 只有角色

## 每張出來先看這五點

1. 同一個境界的四張，尺寸要一模一樣。
2. 把角色那張疊在背景那張上面，要跟完整圖對得上。角色變大、變小、移位都算沒過，請它重出。
3. 放大看格子是不是同一個大小。你貼給我的那張就不一致，我量過，同一排裡 4 點到 9 點的格子都有。指令裡有要求對齊，但工具未必做得到。真的對不齊也沒關係，我可以用程式把圖縮到固定格數再放大，讓它變成真的對齊，代價是細節會少一點。這個我還沒在你的圖上試過。
4. 角色那張的邊緣不能有白邊，也不能有洋紅色殘留。
5. 圖裡的字沒有變成亂碼。
