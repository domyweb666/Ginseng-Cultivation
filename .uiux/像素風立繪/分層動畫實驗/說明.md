# 煉氣男：see-through ＋ Rigby2D 試做（2026-11-18）

先看 `煉氣男_原圖版_對照_現在vs新流程.gif`：左邊是 app 現在的待機動畫，右邊是這次做的。

這次做了兩版：

- 原圖版：角色用原本的像素圖去背，背景用 Codex 生的那張縮回 1008×1260。角色大小、像素都跟 app 現在的一樣。第 0 格和原圖比，只差衣服邊上半格的位移。建議以這版為準。
- Codex 版：角色和背景都讓 Codex 重畫。角色跟原圖有點不一樣，在畫面裡也比較小。檔名都是 `煉氣男_codex版_*`，素材在 `素材/codex版/`。

## 流程

1. 角色和背景拆開。原圖版的角色用 `給多米/煉氣男_只有角色_透明底_1008x1260.png`，再把葉子和頭之間夾到的白色天空清掉。背景用 Codex 生的 `素材/codex版/codex_背景.png`：原本那張「只有背景」是用拉長的像素補洞，不能用。
2. 角色丟給 see-through，種子 42，在 4070 SUPER 上約 11 分鐘。我也試了種子 7，它連頭都沒認出來，程式直接停掉。
3. `split_layers.py` 切成九層，結果看 `煉氣男_原圖版_圖層總覽.png`：
   - 上衣、雙手、腿、木桶用 see-through 的。看得到的地方換回原圖像素，被擋住的地方才用它補畫的。
   - 葉子、頭、左右根鬚是我照位置從原圖切的。
   - 閉眼那層是手畫的。
4. `rig_build.py` ＋ Rigby2D 命令列做骨架和動畫，一輪 9.6 秒。多米要動作幅度大一點，可是身體、衣服、頭、根鬚還是不動（根鬚一擺就像破圖），所以大動作都放在三根骨頭上：葉子、提桶的手、木桶（木桶掛在手底下）。
   - 0 到 2 秒靜止，1.2 秒眨一次眼。
   - 2 秒一陣風從左邊吹來，葉子被吹歪 13 度、盪回來幾下，木桶小晃。
   - 5.6 秒掂一次水桶：手先往下沉 8 像素，再往上收進袖子 36 像素（大約 6 格）把桶提起來，停一下再放下；放下後桶往前盪 8 度，來回盪幾下才停。做法跟 app 舊版的掂水桶一樣：只拆袖口以下的手，袖口和袖子留在原地疊在手上面，手像是收進袖子裡。
   - 8.7 秒連眨兩次眼。
5. 特效不用 Rigby2D。它的粒子是柔邊光點，疊在像素圖上很突兀，多米看了覺得怪，所以改成 `fx.py` 直接在 168×210 的格子上一格一格畫，用 `rig.py` 現成的畫點工具和色票，跟 app 現在的立繪特效同一套做法。每個特效都對應一個動作：
   - 2 秒起風：地上四根草屑被捲起來，一邊翻一邊飄過去。原本還有幾道風線，可是不明顯，疊在角色上看起來像破圖，所以拿掉了。
   - 6.75 秒桶放下來：桶口濺出三滴水，水滴帶一格深藍邊，不然在淺色石階上看不見。
   - 一直都有：背景燈籠的光慢慢閃。
   - 5 秒和 9 秒左右沒有大動作時：紅果各閃一下金色十字。
6. `compose.py` 疊成這幾層，由下到上：背景（不動）、燈籠光、角色、角色前的特效。縮成 168×210，每格取正中央的顏色，160 色共用色盤，一格 0.15 秒，共 64 格。

## see-through 為什麼補不了人蔘頭

它是先判斷每個像素屬於哪個部位，再分別補畫。部位清單固定 23 個，是照動漫人物定的，例如頭髮、臉、眼睛、上衣、手、腿、物件。葉子、紅果、根鬚沒有對應的部位，它也沒有把葉子當成頭髮，所以這幾層是空的。頭它認得出來，但會照人臉的樣子處理：「臉」那層每次都是一團灰色的蛋形。換種子也救不回來，種子 7 更糟，連頭都沒認到。

另外，人蔘頭在原圖上幾乎沒被擋住，就算拆對了，能補的也只有下巴被領口蓋到的那一小塊。

## 過程中修掉的問題

- see-through 補畫上衣時，順手補了被腿擋住的裙子內側，疊上去以後蓋住了腿，裙襬下多一條深色。現在補畫只留在會動的零件後面。
- 根鬚層混到袖口和衣服的碎布，風一吹會跟著擺。現在根鬚只留根鬚的黃色，碎布歸上衣。
- 葉面比較亮的地方被分到根鬚，風吹時葉子會破洞。現在已經拿回葉子層。
- 頭頂兩側的輪廓被分到葉子層，起風時被葉子扯走，頭邊變成碎點。原因有兩個：葉子補洞時把夾在旁邊的頭輪廓也吃進去；頭輪廓的深橘被當成紅果。現在莖以下只留葉子的綠色，紅果只在莖以上認。
- 原圖去背版在葉子和頭之間、手和身體之間，殘留了幾塊白色天空。現在 y 860 以上的白色都清掉了，木桶的水面在那條線以下，不受影響。
- 縮小時原本整格平均顏色，邊會糊掉，現在改成取每格正中央。色盤原本 72 色，根鬚邊緣會變綠，現在改成 160 色。

## 還沒解決的

- 背景換成 Codex 那張以後，提把圈起來的地方原本是白色天空，現在看得到後面的草叢。照常理這樣是對的，只是跟原圖不一樣。
- 草屑很小，在 app 的實際大小下可能不太看得出來。
- 這次的動畫是 64 格。app 現在的格子圖是 96 格（12×8），要換進 app 得把一輪拉長，或改 app 的格數。

## 重跑

```bash
python split_layers.py <角色透明底.png> <see-through 輸出資料夾> <圖層資料夾> 設定_原圖版.json
```

```bash
bash build.sh <圖層資料夾> <背景.png> <工作資料夾> <Rigby2D 原始碼資料夾> 設定_原圖版.json 煉氣男_原圖版
```

換角色時，要改設定檔裡的這些位置：
- 骨頭轉軸 `pivots`
- 莖接頭頂的線 `neck_y`
- 兩側葉尖的位置 `leaf_side_y`、`head_x`
- 左右根鬚分界 `roots_split_x`
- 腿的起點 `legs_y`
- 眼睛框 `eyes`

see-through 的環境和 Rigby2D 原始碼裝在這次會話的暫存資料夾，重開機後可能會不見，要重裝的話：
- see-through：用 uv 開 Python 3.12，再裝 torch 2.8 cu128 和 `requirements.txt`。
- Rigby2D：`npm install`，再跑 `npx playwright install chromium`。

Codex 版的圖層是先手動切的，那時還沒有 `split_layers.py`。Codex 版的成品用的還是 Rigby2D 粒子，沒有重做。

`fx.py` 裡的位置（燈籠、桶口、紅果）是原圖版在格子上的座標，換角色要重抓。
