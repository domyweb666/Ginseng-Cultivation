# 流程與資訊架構

> 2026-11-07 定稿：方案 A 修訂，三頁左右滑。畫面在 Design 畫布第四排：https://claude.ai/artifact/JmL1xLL5C9NMkf3aVGVo1V
> 依據：`01-核心動作卡.md`（閘門 1 已過）。樹狀測試屬閘門 2，結果由多米帶回。

## 結構樹

```
人蔘修煉
├─ 左頁 設定
│   ├─ 身高
│   ├─ 健康 app（讀取／回寫）
│   ├─ 提醒（開關、提醒日）
│   ├─ 資料（匯出、匯入）
│   └─ 刪除全部紀錄
├─ 中頁 境界（預設停這頁）
│   ├─ 境界碑（立繪 160×200、境界、距下一期、根基）
│   ├─ 體組成來源列 → 手動輸入（表單彈出）
│   ├─ 本週／累計／宗門身分
│   ├─ 今天的修煉（左滑刪除、復原）
│   └─ 記一筆修煉 → 表單彈出
├─ 右頁 分析
│   ├─ 境界段：宗門身分、FFMI 走勢、突破紀錄、天梯、境界怎麼算
│   └─ 功法段：總覽、六門功法卡（含 1RM 走勢）、最近修煉、功法等級怎麼算
└─ 全螢幕慶祝（突破、晉升、精進；4.5 秒自動關）
```

三頁用 SwiftUI `TabView(.page)`，底下三個頁點。左右滑是隱藏手勢，所以每頁都留看得見的入口：中頁左上齒輪、右上分析圖示，側頁一個回中頁的箭頭。

## 核心迴圈

量體組成（健康 app 自動帶入或手動）→ 打開 app → 境界碑算好 → 若突破，全螢幕慶祝 → 看還差幾公斤 → 繼續練 → 練完記一筆 → 累計天數與功法等級往上 → 下個月再量。

## 任務路徑與四條岔路

| 路徑 | 正常走 | 成功 | 取消 | 錯誤 | 中斷回來 |
|---|---|---|---|---|---|
| 1 境界那一刻 | 健康 app 有新量測 → 打開 app → 中頁算好 | 境界升了 → 慶祝 → 回中頁 | 慶祝可點任何處提前關 | 健康 app 沒授權 → 境界碑顯示「去設定打開讀取」加手動輸入 | 回到中頁，狀態照資料重算，不留半途畫面 |
| 2 記一筆 | 中頁「記一筆」→ 表單（功法、重量、次數、組數、日期）→ 記下 | 輕震、回中頁、今天的修煉多一行；破紀錄或升級才慶祝 | 取消 → 表單收回、欄位不存 | 重量空白 → 欄位標紅、按鈕不動 | 回來表單還在，填到一半的值保留 |
| 3 手動量體組成 | 中頁來源列「手動輸入」→ 表單（體重、體脂率、選填去脂）→ 結算 | 同路徑 1 的成功 | 取消 → 收回 | 同一天已有量測 → 先問要不要蓋掉 | 同路徑 2 |
| 4 看分析 | 中頁右滑或點右上圖示 → 分析（境界／功法分段） | 看完左滑回中頁 | 無 | 沒資料 → 各卡顯示空狀態一句話，不顯示假圖 | 回來停在上次的分段 |
| 5 改設定 | 中頁左滑或點齒輪 → 設定 | 改完右滑回中頁，立刻生效 | 無 | 刪除全部 → 先問一次，刪完回中頁空狀態 | 回來停在設定 |

## 進入點

| 從哪裡 | 落在哪 |
|---|---|
| 圖示打開 | 中頁 |
| 小工具（小、中、鎖定畫面） | 中頁 |
| Siri「記一下〔功法〕〔重量〕公斤〔次數〕下」 | 不開 app，直接記，回一句 |
| Siri「我現在什麼境界」 | 不開 app，回一句 |
| 每月提醒通知 | 中頁；若健康 app 已有今天的量測，直接算 |

## 畫面清單

1. 設定頁 2. 境界頁 3. 分析頁（境界段、功法段） 4. 記一筆表單 5. 手動輸入體組成表單 6. 全螢幕慶祝 7. 第一次打開只問身高（抓得到健康 app 就跳過）

## 樹狀測試（閘門 2，多米找沒看過的人測，Agent 不扮測試者）

只給受測者看上面的結構樹文字，不給畫面，問他去哪裡找：

1. 你想知道自己離下一個境界還差多少肌肉
2. 你今天練了深蹲 100 公斤 5 下 3 組，想記下來
3. 你想看臥推這半年有沒有進步
4. 你想把 app 裡的紀錄備份出來
5. 你想知道「真傳弟子」是什麼意思、要怎麼升
