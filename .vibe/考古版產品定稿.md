# 考古版產品定稿（人蔘修煉・現狀走讀）

> 考古版。下面每一條是我從 index.html 讀出來的「它現在實際會這樣」，用白話講。每條後面留一格給你勾：**預期**（對，我就是要這樣）／**意外**（咦，我不知道有這個）／**落差**（我以為會這樣但它沒有）。勾完我們才進下一站。
> 對照流程圖：`.vibe/考古版-flowmap.html`（瀏覽器打開）。編號 n01～n21 對應圖上的節點。
> 我可能讀錯。你實際用起來跟這裡寫的不一樣，就是我錯，回報我改。

## 0. 一句話

把重訓變成修仙：體脂秤的數字算境界，槓鈴重量算功法，有練的天數算宗門身分。全部存在這支手機的瀏覽器裡，沒有帳號、沒有雲端。

| 2-1 | 最上面是宗門身分卡：身分名、一句話、進度條、下一階要什麼（再修煉 N 天／突破到某境界）。 | □預期 □意外 □落差 |

| 2-3 | 量過：境界碑顯示最新一筆量測算出的境界（煉氣～渡劫）＋期別（初／中／後）＋FFMI＋去脂體重＋金色進度條＋「距下一期還差 X kg 肌肉」。 | □預期 □意外 □落差 |

| 2-7 | 突破紀錄：只記「第一次踏到某個新期別」的那天和距上一階多久；掉下去再回來不會再記一筆。體脂超過 20% 的量測不算。 | □預期 □意外 □落差 |

| 2-9 | 「境界怎麼算」摺疊說明，裡面寫了「此表以男性標準設計」。 | □預期 □意外 □落差 |

## 4. 錄入分頁（n10）

| # | 它現在實際會這樣 | 你的反應 |
|---|---|---|
| 4-1 | 記一筆修煉：選功法（膠囊按鈕）、重量（引體向上變「加重」）、次數（預設 5）、組數（預設 3）、日期（預設今天）。提示：記最重那一組就好。 | □預期 □意外 □落差 |

## 5. 按下「記下這一練」之後（n11→n12）

| # | 它現在實際會這樣 | 你的反應 |
|---|---|---|
| 5-1 | 先存起來，再依序判斷，只會發生一種：(a) 宗門身分名字變了 → 全螢幕「宗門晉升」＋長老圖；(b) 這門功法第一次記 → 小提示「開練，目前 X 級」；(c) 等級升了 → 全螢幕「功法突破」；(d) 比以前最佳的比值高 → 全螢幕「功法精進」＋多了幾公斤；(e) 都沒有 → 小提示「修煉 +1」。 | □預期 □意外 □落差 |
| 5-2 | 「破紀錄」比的是 1RM ÷ 體重。體重掉了、重量沒變，也可能算破紀錄。 | □預期 □意外 □落差 |

| 5-4 | 存完只清空重量欄，功法、次數、組數、日期留著，方便連著記。 | □預期 □意外 □落差 |
