人蔘修煉 · flowmap（考古版）

成功路徑 失敗路徑 重試 條件分支 呼叫規則引擎／回頭重畫／次要提示（JSON 有完整標籤） 判斷 子流程 ⚠ 推斷：iPhone 上走不到 點節點看掛點；點掛點檔案會亮出所有用到它的節點
🤖 給 Claude Code 的讀圖說明
這份 HTML 包含一個 <script id="flowmap-data" type="application/json"> 區塊。
讀取方式：document.getElementById('flowmap-data').textContent，然後 JSON.parse()。

重要欄位：
- nodes[].trigger_condition：這個狀態的觸發條件
- nodes[].file_responsibilities：每個檔案（區段）在此節點的具體職責
- file_index：反查表，給你一個檔名（區段），告訴你它出現在哪些節點
- edges[].type：success / failure / retry / conditional，代表分支語意
- edges[].call：true 表示「呼叫規則引擎」；edges[].back：true 表示回頭重畫；edges[].minor：次要提示
- nodes[].inferred：true 表示 ⚠ 推斷（iPhone 上走不到的路）；nodes[].subprocess：子流程

這個專案只有一個 index.html，所以「檔案」用「index.html:L起-迄 區段名」表示。
當你修改一個區段時，先查 file_index 找到它涉及的所有節點，
再看每個節點的 edges 確認你的修改是否影響到下游分支。
