## 一句話：這是什麼

給有在重訓的人，包含剛開始的新手，用來把體組成和力量的進步變成看得到的境界與功法，讓他一直練下去。全 app 一張標準表（原本的男性表），不做女性版（你拍板）。

## 核心功能（只有一個）

境界那一刻（你拍板）：量一次體組成，馬上看到自己是什麼境界、還差多少肌肉升下一期。功法、宗門身分、小工具、Siri 全部繞著這一刻轉。

這代表：健康 app 自動帶入體組成是第一優先（讓那一刻少打字）；慶祝畫面是核心的一部分，不是裝飾；記修煉是服務這一刻的習慣線，不是主角。

## 次要功能（排序）

全部繞著「境界那一刻」排，越上面越不能少：

1. 健康 app 自動帶入體重、體脂率、去脂體重、身高；手打的數字回寫健康 app（預設關）
2. 全螢幕慶祝加真的震動；記錄成功輕震
3. 境界頁原樣移植：境界碑、體脂門檻（軟化版）、三格天數、FFMI 走勢、突破紀錄、天梯、「境界怎麼算」說明（保留「此表以男性標準設計」）
4. 第一次打開只問身高（優先抓健康 app，抓到就不問）
5. 錄入頁：丙，單筆不動，按日期分組成「今天的修煉」清單；量體組成表單；設定（身高、健康 app 開關、提醒開關）
6. 功法頁原樣移植，加每門功法的 1RM 走勢線
7. 宗門身分、客卿、執事原樣保留
8. 主畫面小工具（小、中）與鎖定畫面小工具
9. Siri、捷徑：「記一下〔功法〕〔重量〕公斤〔次數〕下」、「我現在什麼境界」
10. 換手機帶得走：量測從健康 app 重建，修煉與身高靠匯出匯入（不做 iCloud，App Store 審核規範 5.1.3 不准健康資料存 iCloud；2026-11-07 你點頭）
11. 匯出 JSON 備份；網頁版補匯出鈕，iOS 第一次打開可匯入
12. 紀錄可編輯；刪除改左滑加復原
13. 每月量測提醒（本機通知，設定裡一個開關；我的預設：做，因為直接服務成功指標）
14. 刪除全部紀錄（安全標準要求；只刪本機與小工具快照，健康 app 裡的不動；2026-11-07 你點頭）

## 明確不做

考古落差清單裡決定砍的，和拷問砍的，全收在這：

- 女性標準表、性別欄位（你拍板：去掉女性版本。說明裡註明以男性標準設計）
- 沒有體脂數字的替代路徑（你拍板：體脂數字是必要的。沒有體脂就沒有境界，空狀態只說「去量一次體脂秤」）
- 教學頁、輪播、多步驟引導（你拍板：引導越少越好。怎麼量體脂留在原有的「境界怎麼算」說明裡）
- claude.ai 資料庫分支與右上角「連線中…／僅存在這台裝置」字樣
- 65 kg 預設體重、174 預設身高（改成第一次打開問，或從健康 app 抓）
- Google Fonts 連線（字體內嵌進 app）
- 兩段式刪除按鈕（改 iOS 慣例：左滑刪除加復原）
- 寫運動到健康 app（沒有真實時長）、Apple Watch 版、即時動態、社群分享卡
- 帳號登入（資料在裝置與使用者自己的 iCloud）
- 課表、訓練計畫、動作教學
- 飲食、卡路里
- 訓練時長、每組逐筆（第 4 題選了丙）
- 排行榜、好友、社群
- 內購、廣告（第一版免費）
- 英文（第一版只繁中）
- iCloud 同步（審核規範 5.1.3 不准把健康資料存 iCloud；2026-11-07 你點頭）

## 怎樣算成功

一個不認識你的人從 App Store 裝了它，三個月後還在量體組成、還在看境界（你拍板）。

之後量的數字：裝機後第 90 天還有量測紀錄的人佔多少。第一版該顧的是「量這件事要夠順」（健康 app 自動帶入、每月量測提醒）和「量完有東西看」（境界、距下一期差多少），不是功能多。

## 邊界／最怕變成

變成要填很多欄位的健身記錄 app，修仙只是換皮（你拍板）。

所以這條線定死：記一筆修煉維持四欄（功法、重量、次數、組數）加日期；量體組成兩欄（體重、體脂率）加選填去脂體重；第一次打開最多問一個問題（身高）。之後任何新功能若要多一個必填欄位或多一頁引導，先回來改這份。

## 我的預設（技術與細節題，你沒推翻就照走）

| 項目 | 預設 | 理由 |
|---|---|---|
| 體脂門檻 | 原樣：10～18 穩固、18～20 浮動、超過 20 不認證、低於 10 偏低 | 跟網頁版一致 |
| 「暫不認證」軟化 | 體脂超標的量測照樣算出境界並顯示，但標「根基不穩」、進度條灰掉，多一句「降到 20% 以下境界才生效，還差 Y%」；突破紀錄與宗門最高境界仍只採計穩固的量測 | 新手多半體脂偏高，只看到一句「不認證」會直接刪 app；修仙邏輯靠「只採計穩固」保住 |
| 客卿、客卿長老、執事 | 保留，天梯說明裡加一段解釋 | 有梗，新手不會踩到 |
| 破紀錄用 1RM ÷ 體重 | 等級照用比值；「功法精進」的煙火要 1RM 真的比上次高才放，只因減重讓比值變高不放煙火、只升等級 | 減脂期會一直收到假煙火，煙火會貶值 |
| 修煉天數＝有記錄的日子 | 保留 | 簡單、誠實 |
| 補登過去日期不放煙火 | 保留 | 防刷煙火 |
| 同一天第二次量體組成蓋掉第一次 | 保留，但蓋掉前要問 | 不問就蓋是靜默覆寫 |
| 慶祝 4.5 秒自動關 | 保留 | 原本就順 |
| 健康 app 授權時機 | 讀取：第一次打開一次問四種（整個 app 唯一主動跳的系統視窗）；寫入：使用者在設定打開回寫時才問 | 引導越少越好；拆兩次問會多跳一個視窗（2026-11-07 你點頭） |
| 最低 iOS | 17 | SwiftData 需要；iPhone XS 之後都能裝 |
| 語言 | 繁體中文（台灣） | 先做你會的 |
| App 名稱 | 人蔘修煉 | 沿用 |
| Bundle ID | org.domyweb.rencan | 你的網域反過來寫。上架後改不了，要改趁現在 |
| iCloud 同步 | 不做 | App Store 5.1.3 不准健康資料存 iCloud；換手機靠健康 app 重建與匯出匯入（2026-11-07 你點頭） |
| 健康 app 寫入 | 預設關，設定裡開 | 有人不想 app 動他的健康資料 |
| 小工具 | 主畫面小（境界加本週天數）、主畫面中（再加距下一期差幾公斤）、鎖定畫面圓形（本週天數） | 先做三種 |
| Siri、捷徑 | 「記一下〔功法〕〔重量〕公斤〔次數〕下」、「我現在什麼境界」 | 兩個最常用的 |
| 舊資料匯入 | 網頁版補「匯出 JSON」鈕，iOS 第一次打開可匯入 | 你自己的紀錄不能丟 |
| 隱私政策 | 放在 domyweb.org 一頁 | 上架必填，有 HealthKit 的 app 一定要有 |
| 收費 | 免費，無內購 | 先看留存 |
| CI 簽章 | 憑證在 Windows 用 openssl 做 CSR、Apple 後台簽、.p12 進 GitHub Secrets；上傳用 xcodebuild 直傳 App Store Connect | 整條路不需要 Mac |
