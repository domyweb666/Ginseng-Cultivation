# 人蔘修煉 iOS 版：一次驗收清單

> 2026-11-16 整理。你說整個 app 做完再驗一次，這份照「拿著手機從頭走一遍」的順序排。
> 每一項前面的方框自己打勾，卡住或覺得怪的在那一行後面寫兩個字，我照著改。
> 標「真機」的是模擬器驗不到、只有你的手機看得到的。

## 走之前先準備

- [ ] TestFlight 裝最新一版：1.0（29），2026-11-17 凌晨出的，這一版有像素立繪。TestFlight 上這一版的說明還寫「多了小工具」，那是上一版留下的字，不用理它
- [ ] iPhone 的 Safari 打開網頁版，按最下面的「匯出 JSON」，檔案先存在「檔案」app。等一下匯入要用
- [ ] 手機的健康 app 裡最好有一筆體重加體脂率（沒有體脂秤就手動加一筆），等一下看它會不會被帶進來

## 一、第一次打開

- [ ] 刪掉舊版重裝，打開。這一頁一出現就會跳健康 app 的讀取授權，一次問五種：身高、體重、體脂率、去脂體重、生理性別（真機）
- [ ] 同意之後，健康 app 裡有的身高和性別已經先填好，你還是改得了。兩樣都抓到會直接進境界頁
- [ ] 沒選性別時「開始」按不下去

## 二、量體組成，看境界

- [ ] 境界頁還沒量過時寫「還沒量過體組成」，按「手動輸入體組成」
- [ ] 填體重、體脂率，下面會先預覽結算後的境界
- [ ] 按「結算境界」：全螢幕「踏入仙途」，有金色和翠綠的粒子飛散，手機會震一下（震動只有真機）
- [ ] 點一下關掉，境界碑上的境界、FFMI、還差幾公斤肌肉，跟網頁版同一筆資料算出來的一模一樣
- [ ] 再輸入一筆體脂 24% 的：境界碑顯示「根基不穩」，沒有煙火
- [ ] 把日期改成上個月補登一筆：只有一句小提示，沒有煙火
- [ ] 同一天再量一次：會先問你要不要蓋掉
- [ ] 分析頁的境界段：宗門卡、FFMI 走勢、突破紀錄、天梯、「境界怎麼算」點開看得懂
- [ ] 系統設定打開「減少動態效果」再結算一次：慶祝沒有粒子

## 三、記修煉

- [ ] 境界頁按「記一筆修煉」。功法六選一，重量只有加減鈕，一格 2.5 公斤（打不出 41 公斤這種數字，你覺得需要再跟我說）
- [ ] 選功法、調重量時，下面的「預估 1RM、幾倍體重、再加幾公斤升下一級」會跟著變
- [ ] 還沒記過任何一筆時記第一筆：全螢幕「引氣入體」，沒量過體重也會放
- [ ] 隔 21 天以上再記一筆：全螢幕「出關」。記之前「今天的修煉」寫「你的 N 天修煉都還在，練一門就出關。」
- [ ] 功法格下面有一行「上次 10 月 3 日・60 公斤 × 5 下 × 3 組」，按加減不會變
- [ ] 記一筆平常的：小提示「修煉 +1」，今天的修煉多一行
- [ ] 記一筆比以前都重的：全螢幕「功法精進」；升了一級是「功法突破」
- [ ] 點今天的修煉其中一行可以改數字存回去
- [ ] 按住一行會跳出選單，選刪除，5 秒內可以按「復原」。這裡原本說好是左滑，實測左滑會被換頁攔掉，所以改成按住
- [ ] 分析頁的功法段：十二張卡的等級、1RM、下一階；點卡進去看得到那門功法的所有紀錄
- [ ] 記一筆的功法分腿、推、拉三排，每排四門；「羅馬尼亞硬舉」這種長名字沒被切掉
- [ ] 分析頁功法段的雷達圖：十二根軸，名字不互相擋到；記過的功法點會往外長
- [ ] Siri 說「記一下前蹲 60 公斤 5 下」或「記一下抱鼎樁…」都聽得懂

## 四、健康 app 連動（全部真機）

- [ ] 在健康 app 手動加一筆「今天」的體重和體脂率，回到人蔘修煉：境界直接算好，而且照樣放慶祝
- [ ] 境界頁中間那一列寫「健康 app・幾月幾日量測」
- [ ] 加一筆「三天前」的再打開：只出一句「從健康 app 帶入 1 筆量測」，沒有煙火
- [ ] 設定頁的健康 app 區打開「量測寫回健康 app」，會再問一次寫入授權。之後手動輸入一筆，到健康 app 裡看得到那筆
- [ ] 設定頁按「從健康 app 重建量測紀錄」，先講會做什麼，按「重建」之後以前的量測會一次帶進來，同一天不會重複
- [ ] 到系統設定把健康 app 的讀取關掉再回來：境界頁多一行「健康 app 讀不到體重和體脂。」和「去設定打開讀取」

## 五、資料帶得走

- [ ] 設定頁「匯入紀錄」選剛剛網頁版匯出的檔：先給你看會新增幾筆，確認後才寫入
- [ ] 匯入之後境界、突破紀錄、累計天數跟網頁版一樣
- [ ] 同一個檔再匯入一次：不會多出重複的
- [ ] 隨便選一個不是這個 app 的檔：用中文說它哪裡不對，什麼都不寫入
- [ ] 「匯出紀錄」：寫著幾筆量測幾筆修煉，還有一句「這個檔案含你的身體數據，自己保管。」，按了跳分享表單
- [ ] 「刪除全部紀錄」：跳出確認視窗，上面寫會刪幾筆。先點視窗外面取消，資料都還在；再按一次選「全部刪除」，境界頁回到還沒量過。身高和性別會留著

## 六、Siri（真機）

- [ ] 「嘿 Siri，用人蔘修煉記一下深蹲」：它會再問幾公斤、做幾下，答完回一句記了什麼、算哪一級。不用打開 app
- [ ] 打開 app，今天的修煉有那一筆
- [ ] 「嘿 Siri，人蔘修煉我現在什麼境界」：回境界、FFMI、還差幾公斤肌肉
- [ ] 手機鎖著的時候這兩句也能用，會唸出 FFMI。你在意別人聽到的話跟我說，改成先解鎖只要一行

## 七、每月提醒

- [ ] 設定頁打開「每月量測提醒」：開關下面先出現一句說明，接著跳通知權限
- [ ] 提醒日可以選 1 到 28 號，時間固定早上 8 點
- [ ] 要驗通知真的會來：把提醒日設成明天，手機時鐘調到明天早上 7:59 等一分鐘（真機）。通知上只有一句話，沒有體重體脂
- [ ] 點通知會開到境界頁
- [ ] 設定頁最下面看得到通知的授權狀態、「到系統設定改」、版本號
- [ ] 「隱私政策」現在點了是 404，原因在最後一段

## 八、小工具

1.0（28）起有小工具。加法：主畫面按住空白處，左上角「編輯」，「加入小工具」，搜尋「人蔘修煉」。鎖定畫面的是按住鎖定畫面，「自訂」，點時間下面那一排。

- [ ] 主畫面加小的：境界加「本週 N 天」；這週還沒練、以前練過的話寫「累計 N 天」
- [ ] 加中的：右邊多一句「距某某期還差幾公斤肌肉」
- [ ] 鎖定畫面加圓形的：只有天數，本週或累計跟小的一樣
- [ ] 打開 app 記一筆，回主畫面，天數已經更新
- [ ] 點小工具會開到境界頁

## 九、像素立繪（2026-11-16 加）

- [ ] 第一次打開那頁、還沒量過的境界頁：雜役服的人蔘是像素風，比以前大一圈
- [ ] 量過之後的境界頁：最上面是一張深色卡，立繪很大。立繪下面是境界名、期別、一行 FFMI 和根基，右邊一顆紅印章
- [ ] 深色卡的底色是你那個境界的顏色。你的手機只看得到自己那一境，七個境界的截圖我放在 `.uiux/像素風立繪/給多米/`
- [ ] 深色卡下面的白卡：「下一期」「還差幾公斤肌肉」、三段進度條，數字跟以前一樣
- [ ] 輸入體脂 24% 的那一筆時：深色卡的小字變淺紅、前面多一個三角形，白卡的進度條變灰
- [ ] 境界碑上的立繪會動：慢慢呼吸、偶爾眨眼，一輪大約 14 秒。看它順不順、有沒有一頓一頓（真機）
- [ ] 貼近看任何一張立繪：格子的邊是利的、每一格一樣大（真機）
- [ ] 打開「減少動態效果」或低耗電模式再回 app：立繪停住不動
- [ ] 突破時的全螢幕慶祝：立繪是像素風。螢幕夠高的手機放大張的，iPhone SE 這類放小張的
- [ ] 切到深色模式：深色卡長得一樣
- [ ] 境界頁開著放五分鐘，手機有沒有變燙、電掉得快不快（真機）
- [ ] 宗門晉升那一刻（累計修煉天數升一階）的長老圖是像素風。這張機器沒有截到圖，要你看

## 十、付費造型（2026-11-18 加，全部真機）

TestFlight 上的內購是沙盒，跳出來的付款視窗會寫「沙盒環境」之類的字，按下去不會扣錢，你用平常的 Apple 帳號就能買。要等內購那一片（M3、M4）上了 TestFlight 才走得了這一段，走之前先確認 App Store Connect 的「付費 App 協議」已經生效，沒生效的話商品讀不到，整頁都會是鎖。

先看還沒買的樣子：

- [ ] 設定頁有一列「立繪造型」，寫著「原版」。境界頁上找不到換造型的入口
- [ ] 點進去：上面一張大圖，下面十二格。原版沒有鎖，另外十一格右下角有小鎖
- [ ] 點水墨：大圖換成水墨，底下出現「購買」加價格（應該是 NT$120）和「恢復購買」。這時按「完成」離開，回境界頁，境界碑還是原版
- [ ] 每一種都點一次看預覽，看有沒有哪一種的圖是破的或空白的

買一種：

- [ ] 點水墨，按「購買」：跳出 Apple 的付款視窗，上面寫的商品名稱是「水墨造型」、價格跟按鈕上一樣
- [ ] 第一次先按取消：回到選造型頁，水墨還是有鎖，沒有跳出錯誤
- [ ] 再按一次「購買」，這次付款：水墨的鎖不見了，點它就換上
- [ ] 回境界頁：境界碑換成水墨，而且會動（M2 做好之後才會動；沒動的話在這一行寫「不動」）
- [ ] 在錄入頁量一筆會突破的體組成（或在健康 app 加一筆）：慶祝畫面的立繪也是水墨
- [ ] 設定頁那一列寫著「水墨」
- [ ] 再點一格沒買的（例如鎏金）：還是有鎖，只能預覽

恢復購買：

- [ ] 刪掉 app，從 TestFlight 重裝，走完第一次打開：境界碑是原版（重裝之後選的造型會回到原版，這是正常的）
- [ ] 到設定頁「立繪造型」：水墨的鎖可能已經不見了；還有鎖的話按「恢復購買」，水墨回來，其他十種照樣鎖著
- [ ] 按「恢復購買」之後畫面上有一句話告訴你結果，不是按了沒反應
- [ ] 開飛航模式再進選造型頁：買過的水墨要嘛還能用，要嘛顯示鎖，但 app 不會當掉、不會跳英文錯誤。關掉飛航模式再進一次，水墨回來

買全套：

- [ ] 買「全套十一種」：付款視窗寫「全套十一種造型」，價格應該是 NT$480
- [ ] 買完十一格的鎖全部不見，隨便點三種，境界碑都跟著換

最後：

- [ ] 換回原版，境界碑變回原版
- [ ] 退款收回造型（退款後那一種變回鎖）TestFlight 上做不出來，由自動測試用模擬的撤銷交易驗。這一條你不用做，知道有這回事就好
- [ ] 整段走下來，畫面上有沒有哪裡出現「解鎖」兩個字。有的話告訴我在哪

## 要你決定或補的東西

- [ ] 隱私政策文稿在 `docs/隱私政策.md`，裡面標「需多米補充」的三處：生效日期、聯絡信箱、開發者名稱
- [ ] 隱私政策要放在哪個網址。我先寫了 https://domyweb.org/rencan/privacy，這頁現在不存在
- [ ] 女性版的「境界怎麼算」「功法等級怎麼算」兩段說明是我寫的，你讀一次
- [ ] 上架那幾步（App Store Connect 的 app 記錄、截圖、說明、隱私問卷、送審）都還沒做，問卷怎麼填在 `docs/上架隱私填寫清單.md`；名稱、副標、描述、送審備註、截圖腳本、送審前你要自己做的事在 `docs/上架文稿.md`
- [ ] 付費造型的價格：單買 120、全套 480。單買過幾種的人買全套沒有折抵，你確認這樣可以

## 我替你決定過、你可能不同意的幾條

完整的在 `.vibe/代決清單.md`，這裡挑影響比較大的：

- 補登的量測會進突破紀錄（跟網頁版一樣每次重排重算）。PRD 寫補登不進，兩條規則互相撞，我選了跟網頁版一致
- 匯入網頁版的檔時，身高會被檔案裡的蓋掉
- 匯出的檔沒有性別，換手機匯入後還會問一次性別
- 健康 app 同一天量好幾次，只取最後一次；本機那天已經有量測就不動
- app 的資料庫會跟著整機 iCloud 備份走。審核員如果認定這算把健康資料存 iCloud，要改成不備份
- 境界碑上少了「目前境界」四個字和境界的一句說明（例如「看得出有在練」），畫布的深色卡上沒有這兩樣
- 根基不穩在深色卡上是淺紅字加三角形，顏色是我挑的
- 窄的手機（SE、mini）上，深色卡比下面的白卡左右各寬一點點；手機開「放大顯示」時立繪左右會被切掉一點
- 低耗電模式要離開 app 再回來才會生效
- 第一次打開就跳健康 app 授權。標準清單原本寫第一次打開不該跳任何授權視窗，那是手填版時期寫的

## 機器已經替你驗過的

你不用重做，知道有這回事就好。

- 規則引擎（境界、功法等級、慶祝判定、匯入檢查、女性版換算）的測試每次推上去都在 Linux 上全部重跑
- 畫面流程由 GitHub 的模擬器自動走一遍並截圖，目前 21 條（2026-11-17 多了七個境界的深色卡、根基不穩、立繪隔三秒有沒有換格）：第一次打開、量體組成、記一筆、編輯、兩種刪除、設定頁各區、匯出、刪除全部、分析頁沒資料時的樣子
- 我在 Limrun 雲端 iPhone 上親手走過兩趟，看了深色模式、慶祝粒子、設定頁各區
- 模擬器驗不到的：震動、體脂秤、健康 app 授權、Siri 語音、通知。這些都在上面標了「真機」
