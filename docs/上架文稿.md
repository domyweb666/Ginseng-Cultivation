## 一、名稱、副標、關鍵字

App Store 只拿名稱、副標、關鍵字欄位這三格來比對搜尋，描述、宣傳文字不算。三格裡同一個詞只要出現一次，重複不會加分。類別「健康與健身」裡的字也不用再寫，所以關鍵字裡沒有「健康」「健身」。

app 裝在手機上顯示的名字是「人蔘修煉」（`Info.plist` 寫死的），跟 App Store 上的名稱可以不一樣。App Store 名稱前四個字一定是「人蔘修煉」，搜品牌的人才找得到。

### 推薦版

名稱（12／30）

```
人蔘修煉－重訓與體脂紀錄
```

副標（14／30）

```
量完體組成，看你練到哪個境界
```

關鍵字（79／100，逗號分隔不加空白）

```
FFMI,修仙,肌肉,增肌,減脂,體重,1RM,深蹲,臥推,硬舉,舉重,槓鈴,力量,肌力,記錄,日記,人參,進度,等級,秤,女生,健美,體態,打卡,習慣,遊戲
```

為什麼這樣排：

- 名稱放「重訓」「體脂」，這兩個是一般人會打的字，修仙那套說法第一次看的人不會搜。
- 副標講別人沒有的那件事：量完會告訴你練到哪一境。「體組成」放副標，跟名稱的「體脂」不重疊。
- 關鍵字放動作名（深蹲、臥推、硬舉）、目標（增肌、減脂）、FFMI。「記錄」跟名稱的「紀錄」是不同字，有人兩種都打，所以兩個都佔到。「人參」是怕有人打成這個字（app 裡 Siri 也認「人參修煉」）。
- 「秤」單獨放，是希望「體脂秤」能用名稱的「體脂」加關鍵字的「秤」湊出來。中文斷詞 Apple 沒有公開規則，湊不湊得出來不確定。
- 「女生」是給搜「女生重訓」的人，這個 app 有女性那一套標準。
- 「遊戲」有一點風險：搜「健身遊戲」的人可能想找的是 Ring Fit 那種會動的遊戲。你覺得會誤導就換成「計算」。

```

副標（17／30）

```
FFMI換算成修仙境界，男女都能用
```

關鍵字（75／100）

```

```

取捨：會搜 FFMI 的人是已經懂的老手，副標直接寫 FFMI，他一眼就知道這是什麼。代價是新手看不懂 FFMI，副標對他沒用。「男女都能用」回答了女生會有的疑問，但這是必答題，放截圖也行。

```

```

```

取捨：FFMI 放名稱分量最重，適合你想先抓懂 FFMI 的老手。名稱裡用了冒號，有審核員不喜歡「品牌：關鍵字」這種寫法，被退的話改成沒冒號的版本：

```
人蔘修煉 FFMI重訓境界
```

### 我推薦推薦版

第一版要的是陌生人搜得到、看得懂。「重訓」「體脂」是新手也會打的字，FFMI 只有老手會打，放關鍵字欄位就夠了。

### 檢查結果

- 三格之間沒有重複的詞，三組都用程式比過（兩個字一組比對）。
- 沒有競品名稱、商標、價格，沒有「第一」「最準」這種字。
- 斷詞：「重訓與體脂」可能被切成「重訓｜與｜體脂」，沒有別的意思。「哪個境界」切法只有一種。
- 關鍵字欄位：App Store Connect 的計數器是算字元。我看過有人說中文是照位元組算（UTF-8 一個中文字 3 個位元組，推薦版是 173 位元組）。如果後台貼進去說超過，從最後面一個一個刪（遊戲、習慣、打卡…）到它接受為止。

### 英國英文那一組（先不填，給你決定）

台灣店面會同時比對繁中和英國英文兩組欄位，多填英文那組等於多一格關鍵字。我先不建議填：app 裡面只有中文，搜英文找進來的人打開看不懂，會刪掉或給低分。之後真的要填，描述第一句要寫「The app interface is in Traditional Chinese.」。

## 二、描述、宣傳文字、新功能說明

### 描述（4000 字以內）

描述只有第一句一定會被看到，所以第一句講「這是什麼」加「要不要註冊」。規範 2.5.1 要求用到健康 app 要在描述裡講，第三段有。價格可以寫在描述裡（截圖上不行）。

```

練了三個月，鏡子裡看不出差別，體脂秤上的數字也說不出什麼，很多人就是這樣停掉的。這個 app 做的事很簡單：把那些數字翻成一個你看得懂、會想往上爬的東西。

▌境界怎麼算
用 FFMI 算，就是用身高校正過的去脂體重指數。煉氣、築基、金丹、元嬰、化神、大乘、渡劫，七個境界，每個分初期、中期、後期。男生女生各一套標準。
體脂要在 20% 以下（女生 27%）境界才算數。超過也照樣算給你看，只是標「根基不穩」，告訴你還差幾 % 就生效。剛開始練、體脂偏高的人，一樣看得到自己在哪。

▌體脂秤量完，打開就算好
體脂秤的數字有同步到 iPhone 的健康 app 的話，打開人蔘修煉，體重、體脂率已經帶進來了，按一下就結算。沒有體脂秤也可以，體重和體脂率自己打。
健康 app 的資料只用來算境界，不會上傳，也不會拿去做廣告。要不要把手打的數字寫回健康 app，你在設定裡自己開，預設是關的。

▌突破的時候會放慶祝
第一次入道、升一期、跨一個大境界，都有全螢幕慶祝，手機會震一下。補登以前的量測不放，免得自己刷。

累計修煉天數會讓你從雜役弟子升到外門、內門、真傳弟子，再往上是長老。

▌不開 app 也看得到
主畫面小工具顯示境界和這週練了幾天，鎖定畫面顯示這週天數。
對 Siri 說「用人蔘修煉記一下深蹲」，它會問你幾公斤、幾下，記好不用打開 app。也可以問它「我現在什麼境界」。

不用註冊，沒有帳號，沒有廣告，沒有分析工具。紀錄只存在這支手機。
換手機的時候，量測從健康 app 重建，修煉紀錄用設定裡的「匯出紀錄」帶走。設定裡也可以一次刪掉全部紀錄。

▌付費的只有造型

要付錢的只有立繪造型。原版像素立繪免費，另外十一種造型可以換：水墨、鎏金、月夜、皮影燈籠、掌機四色、貼紙、粗像素、青花瓷、赤霞夕照、霓虹、翠玉。換了以後，境界碑和慶祝畫面的人蔘全部換成那一種，男女七個境界都有。

```

## 四、送審備註（App Review Information）

貼在 App Store Connect → 你的版本 → App Review Information → Notes。審核員看英文比較快，貼英文那段就好，中文對照在後面。英文那段 3190 字元，這一格上限是 4000。

同一頁的其他欄位：

- 「需要登入」（Sign-in required）：不要勾。沒有帳號。
- 聯絡資訊：你的名字、電話、信箱，審核員有問題會找這個人。
- 附件：不用附。

這個 app 沒有示範模式。程式裡的示範資料（`-rencanSeed demo` 那幾組）只在 Debug 版有作用，TestFlight 和上架版一律不認，審核員用不到。所以備註裡寫的是「自己輸入一筆」的走法，一分鐘內就看得到慶祝畫面。

WHAT THE APP DOES
The user enters, or imports from Apple Health, their weight and body fat percentage. The app calculates FFMI (height-adjusted fat-free mass index) and shows it as a "cultivation realm" from Chinese fantasy fiction. Logged lifts are shown as levels for 12 exercises. NO SIGN-IN, NO DEMO ACCOUNT NEEDED
There is no account and no sign-in. There is no built-in demo mode, so please follow the steps below; it takes about one minute.
