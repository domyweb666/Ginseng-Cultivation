# 上架隱私填寫清單（人蔘修煉）

給多米照著填的。對象是 App Store Connect 的「App 隱私權」（App Privacy）那一頁，加上送審時的審核備註。

結論先講：**資料蒐集那一題選「不蒐集」**，隱私政策網址填 `https://domyweb.org/rencan/privacy`，其他都不用填。

Apple 後台的題目文字會改版。下面每一題我寫的是題意，英文是我查 Apple 說明文件時看到的字（2026-11-16），你在後台看到的字不一樣就以後台為準，照題意選。

## 填之前先備好三樣

1. 隱私政策頁已經放上 `https://domyweb.org/rencan/privacy`，用手機瀏覽器打得開，不用登入。文稿在 `docs/隱私政策.md`。
2. 那一頁裡的生效日期、聯絡信箱、開發者名稱都補好了（文稿裡標「需多米補充」的三處）。
3. 你的 App Store Connect 帳號是帳號持有人、管理員或 App 管理者，其他角色改不了這一頁。

## 第一部分：隱私政策網址

位置：App Store Connect → Apps → 人蔘修煉 → 左邊選單的 App Privacy（App 隱私權）→ Privacy Policy 旁邊的 Edit。

| 欄位 | 填什麼 | 為什麼 |
|---|---|---|
| 隱私政策網址（Privacy Policy URL） | `https://domyweb.org/rencan/privacy` | 必填。app 設定頁裡的「隱私政策」連結寫死連到這個網址，兩邊要是同一頁，審核員會兩邊都點。 |
| 使用者隱私選擇網址（User Privacy Choices URL） | 留空 | 選填。這個 app 沒有帳號，沒有需要到網頁上管理的隱私選項，刪資料在 app 裡就能做。 |

## 第二部分：資料蒐集問卷

位置：同一頁，按 Get Started。

| 題意 | 選什麼 | 為什麼 |
|---|---|---|
| 你或你的第三方合作夥伴，有沒有從這個 app 蒐集資料？ | 沒有（No, we do not collect data from this app） | Apple 說的「蒐集」是指把資料傳出裝置，讓你或合作夥伴之後還拿得到。這個 app 不連網，資料只在手機上，沒有任何東西傳出去。 |

選了「沒有」按 Save，後面就不會再問任何題目。上架後產品頁的隱私標籤會顯示「未蒐集資料」。

最後按右上角的 Publish，跳出確認視窗再按一次 Publish。沒按這顆，你填的東西不會生效。

### 健康與健身那一項怎麼答

照上面選「沒有」的話，這一項根本不會出現，不用答。

這個 app 讀了健康 app 的體重和體脂率，照樣選「沒有」。Apple 在問卷說明裡寫明，只在裝置上處理的資料不算蒐集，不用申報。讀健康 app、算境界、存在手機裡，全部發生在手機上。

後台如果改版，變成要你一項一項勾資料類型，那健康（Health）和健身（Fitness）兩項都不要勾，理由一樣。

### 另一個選法（我不建議）

`.vibe/安全標準.md` 類別 8 當初寫的是申報「健康與健身資料、不與使用者身分連結、不用於追蹤」。那是 11 月 7 日先寫的保守版，這次對過 Apple 對「蒐集」的定義，才改成不蒐集。

照那樣填的話是：選「有蒐集」→ 勾健康 → 用途選 App 功能（App Functionality）→ 不與身分連結 → 不用於追蹤。

我不建議這樣填，兩個原因。第一，產品頁會顯示「這個 app 蒐集你的健康資料」，跟事實相反，使用者看了會以為資料有上傳。第二，Apple 要你按 Publish 時確認填的內容是準確的，填一個沒發生的蒐集，也是不準確。

要走這個選法，`ios/Rencan/PrivacyInfo.xcprivacy` 也得跟著改，兩邊要一致。先講一聲，兩邊一起改。

### 追蹤

問卷選了「沒有」就不會問到追蹤。這個 app 沒有廣告、沒有第三方 SDK、不跟別家公司的資料做比對，所以也不需要跳「允許追蹤」那個系統視窗。

### 以後什麼情況要回來改這一頁

只要加了下面任何一樣，資料就會離開手機，這一頁要回來改成「有蒐集」，`PrivacyInfo.xcprivacy` 和隱私政策也要一起改：

- 分析工具或當機回報服務
- 雲端同步、線上備份
- 帳號登入
- 廣告
- 任何會連網的功能

## 第三部分：HealthKit 審核常被問的點

用到健康 app 的 app，審核會看得比較細。下面是常見的退件原因，和這個 app 現在的狀況。規範條號是 2026-11-16 查的，Apple 會改，以審核員當下的回覆為準。

| 審核員看什麼 | 這個 app 的狀況 | 你要做的 |
|---|---|---|
| App Store 的說明文字有沒有講到跟健康 app 的整合（規範 2.5.1） | 說明文字還沒寫（片 J2） | 說明裡要有一句講「可以從健康 app 帶入體重、體脂率」。漏了會被退。 |
| 授權視窗上那兩段說明講得夠不夠具體（規範 5.1.1） | 讀取那段列了五種資料和用途，寫入那段講了要你自己打開才寫 | 不用動。 |
| app 裡面找不找得到隱私政策，政策有沒有列出讀哪些健康資料（規範 5.1.1、5.1.3） | 設定頁「關於」區有連結；政策文稿列了五種 | 確認網頁真的上線。 |
| 健康資料有沒有存到 iCloud（規範 5.1.3） | 沒有。app 沒有開 iCloud 功能，資料庫在手機本機 | 審核備註裡講一句。 |
| 有沒有把假的或推算的數字寫進健康 app（規範 5.1.3） | 沒有。只寫使用者親手輸入的三種，去脂體重沒填就不寫 | 審核備註裡講一句。 |
| 健康資料有沒有拿去做廣告、給第三方（規範 5.1.3） | 沒有。app 不連網 | 審核備註裡講一句。 |
| 拒絕授權之後 app 還能不能用 | 可以，全部都能手打 | 審核備註裡講一句。審核用的手機多半沒有體脂秤的資料，審核員會走手打這條路。 |
| 審核員找不到健康 app 的功能在哪 | 讀取在第一次打開時問；回寫在設定裡 | 審核備註寫清楚怎麼走到。 |
| 有沒有醫療宣稱（規範 1.4.1） | app 不量測任何東西，數字是使用者輸入或健康 app 來的，FFMI 是照公式算 | 說明文字和截圖不要出現「診斷」「治療」「精準測量」「醫療」這類字。 |
| 需不需要登入帳號才能審 | 不需要，沒有帳號 | 審核資訊裡「需要登入」那一格不要勾。 |

## 第四部分：審核備註草稿

貼在 App Store Connect → 你的版本 → App Review Information → Notes。審核員大多看英文，所以用英文寫。下面是可以直接貼的版本，中文對照在後面。

方括號裡的地方，送審前照 app 當時的實際畫面對一次再貼。

```
This app is a personal strength-training and body-composition log. It works fully offline: it makes no network requests, has no account or sign-in, no ads, no analytics and no third-party SDKs. All data is stored locally on the device only. iCloud is not used.

HealthKit usage
- Read ([asked once on first launch]): body mass, body fat percentage, lean body mass, height, biological sex. These are used only on device to calculate the user's FFMI and the in-app level shown on the main screen.
- Write (off by default): body mass, body fat percentage, lean body mass. Write permission is requested only when the user turns on [the "write back to Health" switch in the Settings page]. Only values the user typed in by hand are written. Values that came from Health or from an imported file are never written back, and the app never writes calculated or estimated values.
- If Health access is denied, the app remains fully usable: height, sex, weight and body fat percentage can all be entered manually. No test account or special hardware is needed.

Health data is never used for advertising or marketing and is never shared with any third party. Nothing leaves the device unless the user chooses "Export" in Settings, which creates a JSON file and hands it to the system share sheet.

Other features
- One optional local notification per month (off by default). Its text contains no health values.
- Two Siri shortcuts: log a lift, and ask for the current level.
- Settings has "Delete all records", which removes all measurements and workout logs stored by the app. Data in the Health app is not affected.

The app does not measure anything itself and makes no medical claims. Privacy policy: https://domyweb.org/rencan/privacy (also linked in Settings > About).
```

中文對照（給你看，不用貼）：

- 第一段：這是個人用的重訓與體組成紀錄 app，完全離線，不發網路請求，沒有帳號、廣告、分析、第三方 SDK，資料只存在裝置上，不用 iCloud。
- 健康 app 的用法：讀五種，第一次打開問一次，只在手機上算 FFMI 和境界。寫三種，預設關，使用者在設定打開開關才問寫入授權，只寫手打的數字，不寫帶進來的、匯入的、算出來的。拒絕授權 app 照樣能用，全部可以手打，不需要測試帳號或特殊硬體。
- 健康資料不做廣告行銷、不給第三方。除非使用者自己在設定按匯出，資料不會離開手機。
- 其他功能：每月一次的本機通知（預設關，內容沒有健康數值）、兩個 Siri 捷徑、設定裡的刪除全部紀錄（不動健康 app 裡的資料）。
- 最後：app 自己不量測，沒有醫療宣稱。附上隱私政策網址。
